# Маршрут в офлайн-превью региона — дизайн

**Дата:** 2026-06-12
**Статус:** дизайн утверждён
**Проблема:** офлайн-режим отвечает только на вопрос «как выглядит местность», но не «куда идти». Скачанный регион хранит лишь тайлы подложки + метаданные (`pointCount` — число, не точки); сами точки маршрута живут только в памяти сессии `useAiRouteSession()` и пропадают при перезагрузке. Превью региона рендерит шесть базовых слоёв без линии маршрута и маркеров. Страница маршрута через PWA-кэш ненадёжна (NetworkFirst, TTL 7 дней, без прекэша).

## Контекст (что уже есть)

- **Запись региона** (`lib/offline/region-store.ts:16-28`): `id, bbox, estimatedBytes, actualBytes, pointCount, regionLabel, dateAdded, lastUsed, status, tilesDone, totalTiles`. IndexedDB `wanderlog-offline` v2, сторы `regions` и `tiles`. Записи безсхемные — новые поля не требуют бампа версии.
- **Точки маршрута** доступны в момент скачивания: `pages/explore.vue` передаёт `selectedRoutePoints: RouteMapPoint[]` в `OfflineDownloadTrigger`, но `download-trigger.vue:83-87` эмитит только `{ bbox, estimatedBytes, pointCount }`.
- **Онлайн-рендер маршрута** (`composables/use-mapbox.ts`): сначала прямая `LineString` по точкам (#2dd4bf), затем асинхронная подмена дорожной геометрией из Mapbox Directions (`fetchMapboxRoadRouteCoordinates`, приватная функция модуля, ≤25 точек, `geometries=geojson&overview=full`). Номерные маркеры — HTML-элементы (`components/explore/route-marker.ts`), попапы — HTML-строки (`createPopupHTML`). Подписи расстояний — symbol-слой (нужны глифы).
- **Офлайн-стиль** (`lib/offline/offline-style.ts`) сознательно без symbol-слоёв: глифы офлайн недоступны. HTML-маркеры и попапы от глифов не зависят. CSS-переменные `--explore-*` на `/offline` доступны (превью уже их использует).

## Дизайн

### Хранение (вариант A — утверждён)

В `OfflineRegion` добавляются два поля:

- `routePoints: RouteMapPoint[]` — массив точек целиком (id, name, lat, lng, day, sequence, markerKind, rationale, длительность, дистанция).
- `routeGeometry: [number, number][] | null` — дорожная геометрия линии из Mapbox Directions, снятая один раз в момент скачивания (мы онлайн); `null`, если запрос не удался или точек больше лимита.

Жизненный цикл данных маршрута = жизненный цикл региона: удаление региона удаляет и маршрут, миграция IndexedDB не нужна.

Отвергнутые варианты:
- **B. Отдельный стор `routes` (regionId → route)** — бамп v2→v3, upgrade-handler, ручная чистка при удалении региона. Выгоды нет: маршрут весит единицы–десятки КБ.
- **C. Полагаться на SW-кэш API** — хрупко (TTL 7 дней, только недавно открытые маршруты), уже отвергнуто при диагностике.

### Поток данных при скачивании

1. `download-trigger.vue` эмитит в payload весь массив `routePoints` (сейчас — только `length`).
2. `fetchMapboxRoadRouteCoordinates` извлекается из `use-mapbox.ts` в общий модуль `lib/explore/road-route.ts`; `use-mapbox.ts` импортирует его оттуда — поведение онлайн-карты не меняется.
3. Download-флоу (`download-sheet.vue` / `use-offline-regions.ts`): `addRegion` сохраняет `routePoints`; параллельно с тайлами запрашивается дорожная геометрия и дописывается в запись региона (`routeGeometry`). Ошибка запроса не валит скачивание — остаётся `null`.

### Рендер в превью (`components/offline/region-preview.vue`)

После события `load` карты, если у региона есть `routePoints`:

- **Линия:** GeoJSON-источник + line-слой; данные — `routeGeometry`, фоллбек — прямые отрезки по точкам в порядке `sequence`. Стиль повторяет онлайн-линию (#2dd4bf, round join/cap).
- **Маркеры:** `createMarkerElement` из `route-marker.ts` как элементы `maplibre.Marker` — нумерация, цвета и aria-метки идентичны онлайн-карте.
- **Попапы:** `maplibre.Popup` с HTML из `createPopupHTML` (день + название) по тапу на маркер.
- **Без подписей расстояний на карте** — это symbol-слой, офлайн нет глифов. Расстояния уходят в список.

### Список точек

- Раскладка модалки: на `md+` список — колонка справа от карты; на мобильном — блок под картой.
- Группировка по дням через `getRouteDayGroups`; строка: номер, название, длительность и/или расстояние (`formatRouteDistance`).
- Клик по строке — `flyTo` к точке.
- Многодневные маршруты показываются целиком (одна линия, все точки); переключатель дней не делаем (утверждено).

### Деградация

Регионы, скачанные до этой фичи (без `routePoints`), рендерятся как сейчас — только тайлы; в футере/панели подсказка «Маршрут не сохранён — скачайте регион заново».

## Тестирование

- **Source-level node-тесты** (стиль `tests/server/offline-*.test.mjs`, раннер `scripts/run-node-tests.mjs`):
  - схема/стор: `addRegion` принимает и сохраняет `routePoints`/`routeGeometry`;
  - download-флоу: trigger передаёт массив точек, sheet пишет геометрию в запись;
  - превью: код добавляет route-источник/слой и маркеры, есть фоллбек на прямые отрезки и ветка деградации;
  - экстракция `road-route.ts` не сломала `use-mapbox.ts` (импорт из нового модуля).
- **Живая проверка** через preview tools на `localhost:3001`: скачать регион с активным маршрутом, открыть превью — линия и нумерованные маркеры видны, попап открывается, список точек кликабелен, у старого региона превью без маршрута + подсказка.
- `pnpm lint:source` — блокер перед коммитом.

## Вне скоупа / риски

- Навигация «как на explore» (шторка шагов, directions к точке, геолокация) — не входит; превью отвечает на «куда идти» статически.
- Дорожная геометрия для маршрутов >25 точек (лимит Mapbox Directions) — честный фоллбек на прямые отрезки.
- Обновление маршрута после скачивания (пересохранение точек в существующий регион) — отдельная итерация; сейчас актуальный маршрут фиксируется в момент скачивания.
- `feed-globe.client.vue` с тем же `absolute inset-0` паттерном — отмечен в прошлом дизайн-доке, к этой фиче не относится.
